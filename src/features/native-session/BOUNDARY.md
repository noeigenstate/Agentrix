# Boundary: Native session view

The view of an agent session that runs without a terminal — Claude through the Agent SDK on the owner's API key, Codex through its app-server. The events the main process publishes are only the data: the conversation is turned into the reading view's entries and drawn by the reading view's own components, with the same scroll, working line, result row and message box. What only this view adds is the requests waiting on the owner, the notice when Claude's session moves to the terminal, and what a run-mode change shows a running session of either kind: the line, the question about background tasks and the owner's draft carried across.

The events' envelope and types are contract §1 (`src/shared/agent-events.ts`). Item `content`, request and plan payloads are read tolerantly by `native-model.ts` and `native-words.ts` (the field names each one reads are listed at the top of those files), and a field that is absent stays absent.

`/status` and `/usage` (and Claude's `/context` and `/cost`) are read-only queries shown in a window over the conversation (`NativePanel`, this module's own, centred above the message box). Main answers them in the send receipt's `local` field; they are no item, bubble or turn of the conversation, and the window is closed by an Esc pressed in its own session view, a press outside or its button (focus returns to the box), and with nothing focused by an Esc on the page (focus stays there); it also closes when its project is hidden.

## Interface
- `NativeSessionView` (`src/features/native-session/NativeSessionView.tsx`) — the view of one terminal's session, or nothing when there is none, given its card's project, draft handoff and error and link handlers; the file also exports `NativeSession`, the view once the session is known; the grid cell renders it
- `NativePathNote` (`src/features/native-session/NativePathNote.tsx`) — the notice over a card: the run-mode change on its way (line and question) over a terminal card, the outcome of a switch (a failed one says the session stayed, one that worked with a warning, restored or stopped says its reason), and a Claude session that moved to the terminal, with its reason and unsent text available to copy without submission
- `useHandoff` (`src/features/native-session/draft-handoff.ts`) — the draft's way across a run-mode switch, held by every terminal card whatever it shows (a card without a message box offers an empty draft): what the view offers main, whether main holds it, and the draft that arrives
- `NativePanel` (`src/features/native-session/NativePanel.tsx`) — the result window of `/status`, `/usage` and Claude's `/context` and `/cost`: one structure `{ agent, title, command, alert?, hero?, groups, readAt }` (`native-panel.ts`) whose groups are rows, chips, quota bars, a composition bar with its legend, or suggested commands; `panel-codex.ts` and `panel-claude.ts` only turn main's facts into it, a value main did not know reads 未知 and a quota at 100% is told as used up with its recovery time; loading shows skeleton bars, never a blank window
- `NativeToast` (`src/features/native-session/NativeToast.tsx`) — the two-second note after `/model`, `/effort` or `/fast`, drawn in the place of the panel
- `useNativeEntries` (`src/features/native-session/native-store.ts`) — every terminal's session as the window knows it; the file also exports `ensureNativeSession`, `refreshNativeSession`, `nativeShown`, `nativeTells`, `terminalSwitch`, `dismissNative`, `dismissNote`, `noteTerminalSwitch` and `useUsageRevision` (window-wide, and with a project id also that project's own: main's `agents:usage-changed` bumps only the project's)
- `launchRoute` (`src/features/native-session/native-bridge.ts`) — whether a new Claude or Codex session starts native, in the terminal or not at all, from the settings and whether a key is saved; the file also exports `nativeBridge`, the one reader of `window.agentrix.nativeSession`, and the bridge's types
- `receiptWord` (`src/features/native-session/native-words.ts`) — how receipts, states, routes, money and quota windows read; the file also exports `money`, `clockWords`, `windowWords`, `reasonWords` and `routeWord`
- `BillingLink` (`src/features/native-session/native-billing-link.ts`) — the text button that opens the console's billing page (one fixed address) for a balance rejection's notice and the usage block's spend row
