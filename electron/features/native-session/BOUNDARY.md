# Boundary: Native session router

Owns provider-neutral session routing, validated renderer IPC, settings and worker SDK registration.

## Owns
- `electron/features/native-session/**`

## Interface
- `createNativeSessions` (`electron/features/native-session/index.cjs`) — compose trusted provider runtimes and register the native IPC namespace
- `choosePath` (`electron/features/native-session/routing.cjs`) — pure shared path choice for the main process and helper; local Codex always selects app-server, and legacy codexView preferences are ignored on read
- `readJson` (`electron/features/native-session/storage.cjs`) — local metadata reads and atomic writeJson persistence
- `createEventStream` (`electron/features/native-session/events.cjs`) — versioned event publication and replay snapshots
- `registerClaudeWorker` (`electron/features/native-session/worker.cjs`) — authenticated helper run registration
- `validEvent` (`electron/features/native-session/validate.cjs`) — bounded public event validation
- `subscriptionLimits` (`electron/features/native-session/usage.cjs`) — the subscription limits main already holds as a limits payload, with nextPath for what a new session takes
- `createProjectAccounts` (`electron/features/native-session/project-accounts.cjs`) — focused pane account reads, cached by the existing account service; no session or background project launch
- `native:commands` (`electron/features/native-session/ipc.cjs`) — sender-guarded `Result<AgentCommand[]>` bound to terminalId and runtimeSessionId; the router checks the host binding before and after asynchronous provider reads

## Invariants
- Session identity is generated by the host and old instances cannot answer requests — test: `tests/native-router-runtime.test.cjs` › "native router owns session identity and rejects old runtime answers"
- API-only never silently changes billing paths; Codex startup failures stay failed without a TUI fallback, and Codex has no switch entries — test: `tests/native-router-runtime.test.cjs` › "api-only does not fall back when native Claude is missing"; test: `tests/native-switch-long-thread.test.cjs` › "Codex resume resume-frame-limit stays on app-server or fails without a terminal"
- A switch never replays a possibly executed message. An owner quota refusal may send only one proved unexecuted input after terminal readiness; drafts or uncertainty return it to the composer, and the automatic send prevents a subsequent pre-input rollback — test: `tests/native-router-runtime.test.cjs` › "fallback at a message boundary never replays the submitted text"; test: `tests/native-api-quota.test.cjs` › "quota fallback Credit balance is too low: same id, safe input sent once after readiness, no intermediate completion"
- IPC accepts bound structured data and rejects renderer execution options — test: `tests/native-router-runtime.test.cjs` › "native IPC denies extra options and accepts only bound structured answers"
- Replay snapshots replace deltas without new execution or notification — test: `tests/native-router-runtime.test.cjs` › "event snapshots replace deltas and replay without advancing sequence"
- Usage computes new-session routing independently of running paths and falls back to held subscription observations without polling — test: `tests/native-router-usage.test.cjs` › "real main assembly reports terminal-only Claude subscription usage without a key or native session"

## Not ours
- Provider processes and provider protocol parsing
- Terminal rendering and terminal proxy sessions
- Renderer components and durable team inbox
