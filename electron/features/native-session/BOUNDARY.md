# Boundary: Native session router

Owns provider-neutral session routing, validated renderer IPC, settings and worker SDK registration.

## Owns
- `electron/features/native-session/**`

## Interface
- `createNativeSessions` (`electron/features/native-session/index.cjs`) — compose trusted provider runtimes and register the native IPC namespace
- `choosePath` (`electron/features/native-session/routing.cjs`) — pure shared path choice for the main process and helper; Codex always selects app-server, and legacy codexView preferences are ignored on read. Router start accepts host-mapped shell launch settings through resolveSpec; renderer start IPC still accepts only agent/resume.
- `readJson` (`electron/features/native-session/storage.cjs`) — local metadata reads and atomic writeJson persistence
- `createEventStream` (`electron/features/native-session/events.cjs`) — versioned event publication and replay snapshots
- `registerClaudeWorker` (`electron/features/native-session/worker.cjs`) — authenticated helper run registration
- `validEvent` (`electron/features/native-session/validate.cjs`) — bounded public event validation
- `subscriptionLimits` (`electron/features/native-session/usage.cjs`) — the subscription limits main already holds as a limits payload, with nextPath for what a new session takes
- `createProjectAccounts` (`electron/features/native-session/project-accounts.cjs`) — focused pane account reads, cached by the existing account service; no session or background project launch
- `history` (`electron/features/native-session/router.cjs`) — coalesced read-only folder history; forgetting a terminal or closing the router aborts its pending lookup, including an SSH connection still being established.
- `native:commands` (`electron/features/native-session/ipc.cjs`) — sender-guarded `Result<AgentCommand[]>` bound to terminalId and runtimeSessionId; the router checks the host binding before and after asynchronous provider reads
- `tokenRate` (`electron/features/native-session/router.cjs`) — synchronous host-only read of the bound runtime's shared meter for the activity pane; no renderer IPC or provider event schema extension

## May import
- `electron/features/agents/agent-usage.cjs` (public account observation reducers)

## Invariants
- Session identity is generated by the host and old instances cannot answer requests — test: `tests/native-router-runtime.test.cjs` › "native router owns session identity and rejects old runtime answers"
- Owner stop consumes the Codex crash marker before the interrupt RPC; late provider ends cannot restore it, while process loss remains eligible for one verified continuation — test: `tests/restore-owner-stop.test.cjs` › "R5 restoreTerminal continues crashes once, but never an owner stop, including late provider events"
- API-only never silently changes billing paths; Codex startup failures stay failed without a TUI fallback, and Codex has no switch entries — test: `tests/native-router-runtime.test.cjs` › "api-only does not fall back when native Claude is missing"; test: `tests/native-switch-long-thread.test.cjs` › "Codex resume resume-frame-limit stays on app-server or fails without a terminal"
- A switch never replays a possibly executed message. An owner quota refusal may send only one proved unexecuted input after terminal readiness; drafts or uncertainty return it to the composer, and the automatic send prevents a subsequent pre-input rollback. A live OS/shell cold start has no elapsed-time cutoff; the source stays visible until the same provider is ready, while owner cancellation disposes the staged PTY — test: `tests/native-router-runtime.test.cjs` › "fallback at a message boundary never replays the submitted text"; test: `tests/native-api-quota.test.cjs` › "quota fallback Credit balance is too low: same id, safe input sent once after readiness, no intermediate completion"; test: `tests/native-switch-main.test.cjs` › "a live terminal cold start can pass fifteen seconds and still resume the exact provider"; "an owner cancellation during terminal startup reaps the staged host and preserves the source"
- IPC accepts bound structured data and rejects renderer execution options — test: `tests/native-router-runtime.test.cjs` › "native IPC denies extra options and accepts only bound structured answers"
- Replay snapshots replace deltas without new execution or notification — test: `tests/native-router-runtime.test.cjs` › "event snapshots replace deltas and replay without advancing sequence"
- Usage computes new-session routing independently of running paths and falls back to held subscription observations without polling; undated connection placeholders and failed quota reads cannot erase dated observations, while newer observations, explicit logout and account identity changes replace them within their own project — test: `tests/native-router-usage.test.cjs` › "real main assembly reports terminal-only Claude subscription usage without a key or native session"; `tests/usage-observation.test.cjs`.
