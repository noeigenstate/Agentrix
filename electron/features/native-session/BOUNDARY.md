# Boundary: Native session router

Owns provider-neutral session routing, validated renderer IPC, settings and worker SDK registration.
The local MCP command identifies the lead provider. The private bootstrap sidecar carries the Claude lead seat.
The authenticated read-only binding selects Claude worker permissions for both the SDK and hidden terminal.

## Owns
- `electron/features/native-session/**`

## Interface
- `createNativeHost` (`electron/features/native-session/host.cjs`) — assemble provider runtimes and router callbacks, register the worker broker and handle the unavailable runtime fallback
- `createNativeSessions` (`electron/features/native-session/index.cjs`) — compose trusted provider runtimes and register the native IPC namespace
- `choosePath` (`electron/features/native-session/routing.cjs`) — the path choice in the shape the dispatcher's worker reads, a wrapper of claude-runtime's `decide()` until R4; Codex always selects app-server, and legacy codexView preferences are ignored on read. Router start accepts host-mapped shell launch settings through resolveSpec; renderer start IPC still accepts only agent/resume.
- `readJson` (`electron/features/native-session/storage.cjs`) — local metadata reads and atomic writeJson persistence
- `createEventStream` (`electron/features/native-session/events.cjs`) — versioned event publication and replay snapshots
- `registerClaudeWorker` (`electron/features/native-session/worker.cjs`) — authenticated helper run registration; bounded Claude effort, fast and the read-only binding are forwarded to its selected runtime
- `validEvent` (`electron/features/native-session/validate.cjs`) — bounded public event validation
- `subscriptionLimits` (`electron/features/native-session/usage.cjs`) — the subscription limits main already holds as a limits payload, with nextPath for what a new session takes
- `createProjectAccounts` (`electron/features/native-session/project-accounts.cjs`) — focused pane account reads, cached by the existing account service; no session or background project launch
- `createHostInputs` (`electron/features/native-session/host-inputs.cjs`) — what the router reads from the app shell over its deps: each agent's connection and subscription limits, the usage inputs, the connection test's spec, and a native session's environment and its spec (`nativeSpec`, the router's resolveSpec)
- `history` (`electron/features/native-session/router.cjs`) — coalesced read-only folder history; forgetting a terminal or closing the router aborts its pending lookup, including an SSH connection still being established. The synchronous host-only `tokenRate` reads the bound runtime meter without adding IPC.
- `native:commands` (`electron/features/native-session/ipc.cjs`) — sender-guarded `Result<AgentCommand[]>` bound to terminalId and runtimeSessionId; the router checks the host binding before and after asynchronous provider reads. `native:run-options` accepts a read or a Codex permissions patch. Model, effort and fast patches return `routing-owned`.

## Invariants
- Session identity is generated by the host and old instances cannot answer requests — test: `tests/native-router-runtime.test.cjs` › "native router owns session identity and rejects old runtime answers"
- Owner stop consumes the Codex crash marker before the interrupt RPC; late provider ends cannot restore it, while process loss remains eligible for one verified continuation. Read-only /status and /usage (and Claude's /context and /cost) preserve owner-stop and input control flags, and refuse mid-switch or without the API path instead of leaving an unsent bubble — test: `tests/restore-owner-stop.test.cjs` › "R5 restoreTerminal continues crashes once, but never an owner stop, including late provider events"; test: `tests/native-codex-status.test.cjs` › "read-only /status does not clear an owner stop when a late interrupted turn arrives".
- API-only never silently changes billing paths; Codex startup failures stay failed without a TUI fallback, and Codex has no switch entries — test: `tests/native-router-runtime.test.cjs` › "api-only does not fall back when native Claude is missing"; test: `tests/native-switch-long-thread.test.cjs` › "Codex resume resume-frame-limit stays on app-server or fails without a terminal"
- A provider limit's terminal switch is told in the words of its code, whole sentences only. A final rate limit moves only the session that received it; credits and an account limit are the key's and move every owner session — test: `tests/native-api-quota.test.cjs` › "the terminal switch names the limit that moved the session: credits, a rate limit and an account limit each in their own words"; test: `tests/native-api-quota.test.cjs` › "a final rate limit stops and moves only the session that received it; another owner session in the project keeps the API"; test: `tests/native-api-quota.test.cjs` › "credits belong to the key: another owner session moves to the terminal too, and another project meets them as well". The router's `reconcile()` returns its settle point: it resolves once the pass has run and every change it started has settled, so a caller awaits it and never counts event-loop turns; `settled()` is the same point without asking for a pass — test: `tests/native-api-quota.test.cjs` › "only a newly opened owner session can spend the bounded API trial; another new session uses terminal". A switch never replays a possibly executed message. An owner quota refusal may send only one proved unexecuted input after terminal readiness; drafts or uncertainty return it to the composer, and the automatic send prevents a subsequent pre-input rollback. A live OS/shell cold start has no elapsed-time cutoff; the source stays visible until the same provider is ready, while owner cancellation disposes the staged PTY — test: `tests/native-router-runtime.test.cjs` › "fallback at a message boundary never replays the submitted text"; test: `tests/native-api-quota.test.cjs` › "quota fallback Credit balance is too low: same id, safe input sent once after readiness, no intermediate completion"; test: `tests/native-switch-main.test.cjs` › "a live terminal cold start can pass fifteen seconds and still resume the exact provider"; "an owner cancellation during terminal startup reaps the staged host and preserves the source"
- A failed change whose reason is only the general sentence carries its `cause` in the switch state (the failure's code, or its message, as one bounded line), and the next change starts without it — a failure the owner or a test cannot tell apart cannot be fixed — test: `tests/native-switch-runtime.test.cjs` › "I4: preparation failure retains the old path with a readable reason and never retries at idle"
- IPC accepts bound structured data and rejects renderer execution options. The host selects the lead seat at startup, resume and /new. Native model, effort and fast commands are refused before provider work or owner input tracking; run options take a Codex permissions choice only from `CODEX_PERMISSIONS`, the router keeps a session's choice in its spec for its next conversation and never writes the Settings default — test: `tests/native-router-runtime.test.cjs` › "native IPC denies extra options and accepts only bound structured answers"; test: `tests/codex-permissions.test.cjs` › "the router keeps /permissions for this card’s session and its next conversation, never for the Settings default" test: `tests/codex-slash.test.cjs` › "Codex /new takes the current seat and rejects option updates on a retired binding"; test: `tests/native-parity-backend.test.cjs` › "native controls refuse routing patches with the shared code and forward permissions only"
- Replay snapshots replace deltas without new execution or notification — test: `tests/native-router-runtime.test.cjs` › "event snapshots replace deltas and replay without advancing sequence"
- Usage computes new-session routing independently of running paths and falls back to held subscription observations without polling; undated connection placeholders and failed quota reads cannot erase dated observations, while newer observations, explicit logout and account identity changes replace them within their own project — test: `tests/native-router-usage.test.cjs` › "real main assembly reports terminal-only Claude subscription usage without a key or native session"; `tests/usage-observation.test.cjs`.
