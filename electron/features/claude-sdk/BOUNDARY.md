# Boundary: Claude SDK runtime

Owns the host's Claude Agent SDK sessions, protected credentials, worker tool decisions and local API accounting.

Owner and worker entrypoints remain the CLI default. Ownership is host-observed session identity, persisted locally for owners and read from the team journal for workers; the old agentrix-sdk transcript marker remains readable, while unclassified old sdk-ts prompts stay excluded.

Owner sessions currently keep tool and hook environment inheritance; dispatch workers enable the CLI's subprocess scrub. A2 is awaiting the owner's answer; the existing behavior is retained in the meantime, not an isolation guarantee. API routing is pinned in a private session settings file from host and user sources; repository env and helper settings cannot choose the destination. Routing secrets never enter argv. The saved key remains in the child environment, never the settings file or argv; project/local env overrides found at launch are refused. This does not attest effective key bytes against later config changes or active hooks. Project hooks still inherit it under the retained A2 behavior.

Project hooks remain enabled for workers, matching the trusted project's CLI behavior. Worker scope policy constrains the model's requested inputs; it does not sandbox project hooks, which can execute commands and rewrite an allowed input to a path outside the worker scope. This is an explicit owner decision, not an isolation guarantee.

## Interface
- `createClaudeRuntime` (`electron/features/claude-sdk/index.cjs`) — injected SDK session factory, credentials, usage and availability; the file also exports `netRequest`, which gives the connection test Electron net (the session's proxy) in the shape of https.request
- `createSdkLoader` (`electron/features/claude-sdk/runtime.cjs`) — deferred ESM loading from development or unpacked production paths
- `inspectClaudeExecutable` (`electron/features/claude-sdk/executable.cjs`) — the Claude Code the native path runs, from claude-runtime's locator (`locator`: main's shared one, `fresh`: read the stored Windows PATH again first; without one a locator of the given options searches afresh), and whether it meets the minimum version; main reads it to say what a new session takes. One found says where (`via`, `fileShown`) and, when the terminal runs another, older one, `notice: 'cli_split_versions'` with `split.terminal`; a missing result names why: none found (with how many PATH folders and which install folders were searched, home as ~, and an npm package found without its native program), or the file found whose version check timed out, failed to run or printed no version; the check's deadline yields to an exit already waiting while main was busy, and output that never closes is let go after a short grace, so the check always ends; `resolveClaudeExecutable` gives that file to a session — test: `tests/claude-sdk-runtime.test.cjs` › "a native executable whose version check fails is reported with the reason and file, never as not found"
- `commands` (`electron/features/claude-sdk/session.cjs`) — a native-safe command catalog from the live SDK, its replacement pushes or the shared file catalog before a query exists; listing never starts a query

## Invariants
- Owner queries stay open at idle. A query may use the full remaining monthly allowance, with no fixed per-turn cap; an unset month budget omits maxBudgetUsd. Every query starts through `openQuery`, which passes only a positive finite cap (Claude Code exits before initialize for any other); the billing probe sends no input and takes none. A month with nothing left starts no Claude Code: the refusal names its cause (budget set to 0, spent, or held by other sessions or unconfirmed spend) before input, and the route says it — test: `tests/claude-sdk-budget.test.cjs` › "every SDK query starts through openQuery, which passes only a positive finite cap"; test: `tests/claude-sdk-budget.test.cjs` › "a session with no allowance left starts no Claude Code and says why before any input"; test: `tests/claude-sdk-budget.test.cjs` › "a month budget set to zero: the connection test reads billing without a cap and the path says why". Explicit sends renew changed allowance only at safe message boundaries. A live query retains ownership of an uncertain reservation until later accounting evidence; other queries cannot spend it. Listing commands never starts a query; live command feedback is visible while historical machine records stay filtered, and the six native controls are advertised. Returned shell background jobs survive later interrupts and foreground deadlines; close still reaps them. Rejected model delivery retains shell output and names that it was not sent, including accepted shell inputs whose real CLI result fails without a parent model reply. The notice precedes completion and fallback; shell commands are never replayed as fallback prompts. A read of runOptions is lazy; acknowledged model, effort and fast choices survive renewal, including successful raw /model commands identified by the CLI result; reply models never become configuration. New conversations migrate the binding before retiring the previous provider. Owner credit/spend refusals remain scoped until a successful probe, explicit invalidation or successful use; one new session per ten minutes may try again. A console balance that has run out ("credit balance is too low", from the model list, the token count, stderr or a turn) is that refusal, told by its cause and never in Anthropic's or the CLI's words — test: `tests/claude-sdk-connection.test.cjs` › "a console balance that has run out is named on the key line and moves new sessions to the terminal, never in Anthropic's words"; test: `tests/claude-sdk-connection.test.cjs` › "a turn the console balance refused is told by its cause, never in the CLI's words".
