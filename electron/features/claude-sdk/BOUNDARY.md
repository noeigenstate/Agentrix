# Boundary: Claude SDK runtime

Owns the host's Claude Agent SDK sessions, protected credentials, worker tool decisions and local API accounting.

GUI Agent and Task hooks read accepted seats from the private sidecar at call time, with the launch snapshot as fallback.
PreToolUse preserves all input fields except the supported model and effort it applies.
PreToolUse reports the provisional values by tool-use ID. PostToolUse reconciles the final input. A rewrite failure leaves worker policy in force.
Unsupported choices use the reading view's existing alert once per tool-use ID.

Owner and worker entrypoints remain the CLI default. Ownership is host-observed session identity, persisted locally for owners and read from the team journal for workers; the old agentrix-sdk transcript marker remains readable, while unclassified old sdk-ts prompts stay excluded.

Owner sessions currently keep tool and hook environment inheritance; dispatch workers enable the CLI's subprocess scrub. A2 is awaiting the owner's answer; the existing behavior is retained in the meantime, not an isolation guarantee. API routing is pinned in a private session settings file from host and user sources; repository env and helper settings cannot choose the destination. Routing secrets never enter argv. The saved key remains in the child environment, never the settings file or argv; project/local env overrides found at launch are refused. This does not attest effective key bytes against later config changes or active hooks. Project hooks still inherit it under the retained A2 behavior.

Project hooks remain enabled for workers, matching the trusted project's CLI behavior. Owner questions still reach canUseTool under bypassPermissions.
Worker scope policy constrains the model's requested inputs and applies the bound read-only flag; it does not sandbox project hooks, which can execute commands
and rewrite an allowed input to a path outside the worker scope. This is an explicit owner decision, not an isolation guarantee.
Dispatch sessions offer only the built-in tools the worker policy can allow at that access level. PreToolUse denials give a specific reason and a direction to stop.
The worker stream carries denied work with a reason code and a short action summary. Bookkeeping denials stay in the audit, and summaries omit command arguments and file contents.

## Interface
- `apiEnvironment` (`electron/features/claude-sdk/index.cjs`) — also exports listModels; main composes a model-only catalog probe through these exports: scrub alternate authentication/routing before injecting the saved key into the SDK environment, and list model ids through an injected request. Neither function reads stored credentials; main owns that read and tests inject synthetic keys or sources.
- `createClaudeRuntime` (`electron/features/claude-sdk/index.cjs`) — injected SDK session factory, credentials, usage and availability; GUI specs may inject `onSubagent(signal, { runtimeSessionId, providerSessionId, folder })` for C-15 lifecycle reporting to the current host; synthetic stops include optional `outcome: 'killed'`, while SDK stops omit it; the file also exports `netRequest`, which gives the connection test Electron net (the session's proxy) in the shape of https.request
- `createSdkLoader` (`electron/features/claude-sdk/runtime.cjs`) — deferred ESM loading from development or unpacked production paths
- `inspectClaudeExecutable` (`electron/features/claude-sdk/executable.cjs`) — the Claude Code the native path runs, from claude-runtime's locator (`locator`: main's shared one, `fresh`: read the stored Windows PATH again first; without one a locator of the given options searches afresh), and whether it meets the minimum version; main reads it to say what a new session takes. One found says where (`via`, `fileShown`) and, when the terminal runs another, older one, `notice: 'cli_split_versions'` with `split.terminal`; a missing result names why: none found (with how many PATH folders and which install folders were searched, home as ~, and an npm package found without its native program), or the file found whose version check timed out, failed to run or printed no version; the check's deadline yields to an exit already waiting while main was busy, and output that never closes is let go after a short grace, so the check always ends; `resolveClaudeExecutable` gives that file to a session — test: `tests/claude-sdk-runtime.test.cjs` › "a native executable whose version check fails is reported with the reason and file, never as not found"
- `commands` (`electron/features/claude-sdk/session.cjs`) — a native-safe command catalog from the live SDK, its replacement pushes or the shared file catalog before a query exists; listing never starts a query. models() retains resolved values, aliases, advertised efforts and fast capability; query settings use the host's frozen launch seat, including fast mode

## Invariants
- SDK sub-agent callbacks answer `{}` immediately and add no context; folder discovery and C-15 reporting stay ordered on the run's report chain. Each query tracks its reported starts and sends the remaining stops once on retirement, using cached bindings before ownership is dropped; invalid tool-use IDs become null. An interrupted turn queues cleanup after already acknowledged reports and before later-turn reports, using its background snapshot and timestamp. It stops only foreground children and retains children in `run.background`, matched by agent id to the task id or by the start's tool-use ID to the task's `tool_use_id`; full query retirement stops both. Every synthetic stop carries `outcome: 'killed'`; a real SDK SubagentStop has no outcome and remains completed by default. The current native host binds the contained transcript path before delivering a row, and retired queries or hosts cannot change it. Child transcripts supply their own rates and never enter parent usage. Equivalent normalized or real folder paths retain native rows across terminal handoff.
